Bill History Data

The Bill History data is available for sessions dating back to 1969, and provided via a downloadable ZIP archive. Each archive contains an XML file which contains the Bill History for all bills and resolutions (House and Senate). The current session is updated hourly.

What's new - February 2026
The XML file is now updated hourly, Monday through Friday! Additionally, the generated XML now includes the date a bill was updated, links to bill text for each printer's number, co-sponsorship memo and amendments.
